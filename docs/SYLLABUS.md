## Research and change control

Before each lesson, check current official documentation, papers, API deprecations, security guidance and relevant industry practice. Keep source links and access dates in lesson notes. If research reveals an important missing topic, propose a documented amendment with dependency, reason and coverage impact; do not silently rewrite the frozen syllabus. Keep legacy API names for historical roadmap coverage, but implement using supported APIs. Mastery requires practice and assessment, not just reading.
